# Flower photos for the intro frame

All images come from **Pixabay** under the
[Pixabay Content License](https://pixabay.com/service/license-summary/): free for
commercial use, no credit required. (You can't sell the images on their own unchanged,
or use them in a misleading way.) Some are labeled as AI-generated on Pixabay.

- `originals/`: the transparent PNGs as downloaded (1280 px), untouched.
- `gold/`: the versions the intro uses. Each is recolored to a different shade of gold
  (`rich`, `champagne`, `antique`, `rose`, `honey`), downsized to 560 px max, and saved as WebP.
  Sheets with several flowers were cut into single pieces, so one original can appear
  as `name-0`, `name-1` and so on.

Each original's address is `https://cdn.pixabay.com/photo/<date path>/<name>_1280.png`.
To find its Pixabay page, search Pixabay for the number at the end of the name
(for example `8472201`).
